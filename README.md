# 📌 Project Overview

This project performs a complete Exploratory Data Analysis (EDA) on a large Swiggy food delivery dataset.

The objective is to discover customer ordering patterns, revenue trends, restaurant performance, geographical insights, food preferences, and business KPIs using Python.

The project demonstrates practical Data Analytics skills including:

- Data Cleaning
- Data Exploration
- KPI Generation
- Feature Engineering
- Business Insight Generation
- Data Visualization
- Statistical Analysis
